# Карта земель Ыш

Интерактивная карта мира: нажимаете на место, и карта плавно приближается. Внутри открываются новые точки. В домах живут персонажи, с ними можно поговорить.

Сделано на Next.js (App Router, TypeScript), без сторонних библиотек.

## Запуск

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Как выложить в интернет

1. Загрузите папку в репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) нажмите **Add New → Project** и выберите репозиторий. Настройки не нужны: Vercel сам поймёт, что это Next.js.
3. Чтобы жители отвечали через ИИ, добавьте ключи в **Settings → Environment Variables** (см. ниже) и сделайте Redeploy.

После этого каждый `git push` будет сам обновлять сайт.

## Где что лежит

```
src/data/world.ts      ← структура мира: места, уровни, координаты точек
src/data/npcs.ts       ← жители: имя, характер, что знают, внешность заглушки
src/art/scenes.ts      ← рисунки-заглушки сцен (деревня Кружье)
src/art/rooms.ts       ← рисунки-заглушки комнат и персонажей
src/components/        ← интерфейс: Explorer (переходы), Spots (точки), Interior (дом и чат)
src/lib/camera.ts      ← камера: плавное приближение
app/api/chat/route.ts  ← сервер для разговоров с жителями
public/map.webp        ← общая карта
public/scenes/         ← сюда кладите свои картинки локаций
public/rooms/          ← сюда кладите свои картинки комнат
```

Почти всё, что нужно менять, находится в `src/data/`.

## Как добавить место

Откройте `src/data/world.ts` и добавьте объект в `children` нужного родителя:

```ts
{ id: "rynok", name: "Рынок", type: "leaf", at: { x: 48, y: 14.6, r: 4.6 } }
```

- `id` пишется латиницей через дефис. Из него собирается адрес страницы (`/pitychiy-les/kruzhye`).
- `at` — где точка лежит на картинке родителя, в процентах: `x` слева, `y` сверху, `r` — радиус кольца в процентах ширины.
- `type`:
  - `leaf` — место пока закрыто туманом;
  - `map` — приближение на общей карте (нужен `view`) с вложенными точками;
  - `scene` — отдельная картинка локации;
  - `interior` — дом с жителем (нужен `npc`);
  - `locked` — точку видно, но открыть нельзя.

**Как найти координаты точки:** откройте картинку в любом редакторе и наведите курсор на нужное место. Разделите его координату X на ширину картинки и умножьте на 100. С Y то же самое, только делите на высоту.

## Как поставить свои рисунки вместо заглушек

- **Локация:** положите `public/scenes/kruzhye.webp` и в `world.ts` у Кружья замените `art: "kruzhye"` на `image: "/scenes/kruzhye.webp"`. Поле `aspect` должно равняться ширине картинки, делённой на высоту. После этого заново расставьте `at` у домов.
- **Комната:** положите `public/rooms/miron.webp` и добавьте жителю в `npcs.ts` строку `roomImage: "/rooms/miron.webp"`. Персонаж-заглушка пока остаётся поверх комнаты.
- **Общая карта:** замените `public/map.webp`. Если поменялись пропорции, обновите `MAP_ASPECT` в `world.ts`.

Картинки лучше сохранять в WebP: так они весят в несколько раз меньше PNG.

## Разговоры с жителями: бесплатно

Сервер пробует сервисы по очереди: **Gemini → Groq → Cloudflare Workers AI**. Если все недоступны, житель отвечает заготовленными фразами из `npcs.ts`. Подойдёт любой набор ключей, даже пустой.

| Переменная | Где взять |
|---|---|
| `GEMINI_API_KEY` | https://aistudio.google.com/apikey |
| `GROQ_API_KEY` | https://console.groq.com/keys |
| `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN` | панель Cloudflare → Workers AI (токен с правом Workers AI) |

Для запуска на своём компьютере скопируйте `.env.example` в `.env.local` и вставьте ключи.

**Не привязывайте карту ни к одному из сервисов.** Тогда платить нечем: когда дневной лимит заканчивается, сервис отказывает, и отвечает следующий. Бесплатные лимиты и названия моделей иногда меняются. Модель можно поменять переменными `GEMINI_MODEL`, `GROQ_MODEL` и `CLOUDFLARE_MODEL`.

Одному посетителю можно отправить 30 сообщений за 10 минут. Число меняется переменной `CHAT_LIMIT_PER_10_MIN`.
