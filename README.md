# Люприки

Сайт о мире люприков. Сейчас в нём два раздела:

- **Карта мира** (`/map`): нажимаете на место, и карта плавно приближается. Внутри открываются новые точки. В домах живут персонажи, с ними можно поговорить. Карту на телефоне можно двигать пальцем.
- **Энциклопедия** (`/encyclopedia`): разделы «Персонажи», «Локации», «Флора», «Фауна» и «Вещички», в каждом карточки с картинкой и описанием.

На главной (`/`) — две большие плашки этих разделов, в шапке каждой страницы — переключатель между ними.

Сделано на Next.js (App Router, TypeScript), без сторонних библиотек.

## Запуск

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

> **Windows, PowerShell:** если `npm` пишет «выполнение сценариев отключено в этой системе», один раз выполните `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или запускайте `npm.cmd run dev`.

## Энциклопедия

Все карточки лежат в `src/data/encyclopedia.ts`. Чтобы добавить карточку, допишите объект в `ENTRIES`:

```ts
{
  id: "vkusnika",            // латиница через дефис, уникальный
  section: "flora",          // characters | locations | flora | fauna | items
  name: "Вкусника",
  kind: "ягода",             // подпись над названием, можно не писать
  text: "Первый абзац.\n\nВторой абзац.",
  fact: "Интересный факт",   // можно не писать
  image: "/encyclopedia/vkusnika.webp", // можно не писать — будет заглушка
  map: "holmy",              // id места из world.ts, можно не писать
}
```

- **Картинка:** положите файл в `public/encyclopedia/` и укажите путь в `image`. Лучше всего подходят картинки 4:3 (например, 1200×900) в WebP или JPG.
- **Связь с картой:** если указать `map`, в карточке появится «Показать на карте», а на карте у этого места — «Читать в энциклопедии».
- **Ссылка на карточку:** `/encyclopedia/flora#vkusnika` откроет страницу раздела сразу с этой карточкой.
- **Новый раздел:** добавьте его в `SECTIONS`, тип `SectionId`, значок в `src/components/site/Icons.tsx` и цвета в `app/site.css` (блок «цвета разделов»).

## Как выложить в интернет

1. Загрузите папку в репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) нажмите **Add New → Project** и выберите репозиторий. Настройки не нужны: Vercel сам поймёт, что это Next.js.
3. Чтобы жители отвечали через ИИ, добавьте ключи в **Settings → Environment Variables** (см. ниже) и сделайте Redeploy.

После этого каждый `git push` будет сам обновлять сайт.

## Где что лежит

```
art-src/map/           ← исходные PNG-слои карты из Procreate (имя файла = id слоя)
scripts/build-map.mjs  ← готовит слои для сайта: npm run map
src/data/encyclopedia.ts ← энциклопедия: разделы и карточки
src/data/world.ts      ← структура мира: места, уровни, координаты точек
src/data/npcs.ts       ← жители: имя, характер, что знают, внешность заглушки
src/art/scenes.ts      ← рисунки-заглушки сцен (деревня Кружье)
src/art/rooms.ts       ← рисунки-заглушки комнат и персонажей
src/components/        ← интерфейс: Explorer (переходы), Spots (точки), Interior (дом и чат)
src/lib/camera.ts      ← камера: плавное приближение
app/api/chat/route.ts  ← сервер для разговоров с жителями
public/map/            ← готовые слои карты (создаются командой npm run map)
public/scenes/         ← сюда кладите свои картинки локаций
public/rooms/          ← сюда кладите свои картинки комнат
```

Почти всё, что нужно менять, находится в `src/data/`.

## Как добавить место

Откройте `src/data/world.ts` и добавьте объект в `children` нужного родителя:

```ts
{ id: "rynok", name: "Рынок", type: "leaf", at: { x: 48, y: 14.6, r: 4.6 } }
```

- `id` пишется латиницей через дефис. Из него собирается адрес страницы (`/map/kruzhye/dom-kartografa`). Старые адреса без `/map` перенаправляются сами.
- `layer` — id слоя карты. У такого места нажимается сам рисунок, а камера сама подбирает приближение.
- `at` — у места со слоем это место подписи; у остальных — центр кольца, `r` — его радиус. Всё в процентах холста: `x` слева, `y` сверху.
- `type`:
  - `leaf` — место пока закрыто туманом;
  - `map` — приближение на карте с вложенными точками;
  - `scene` — отдельная картинка локации;
  - `interior` — дом с жителем (нужен `npc`);
  - `locked` — точку видно, но открыть нельзя.

**Как найти координаты точки:** откройте превью карты (`art-src/map-preview.png`) в любом редакторе и наведите курсор на нужное место. Разделите координату X на ширину картинки (3840) и умножьте на 100. С Y то же самое, только делите на высоту (2160).

## Карта и слои

Карта собирается из отдельных слоёв: материк снизу, поверх него каждая локация. Поэтому каждая локация нажимается точно по своему силуэту, приподнимается при наведении, а при приближении остальные бледнеют.

**Как обновить карту после перерисовки:**

1. Экспортируйте из Procreate каждый слой в PNG с прозрачностью. Все слои должны быть **на одном холсте одного размера** (сейчас это 3840×2160).
2. Назовите файлы латиницей так же, как раньше: `kruzhye.png`, `pitychiy-les.png`, `materik.png` и так далее. Положите их в `art-src/map/` с заменой.
3. Выполните `npm run map`. Скрипт обрежет пустоту вокруг каждого слоя, сохранит лёгкие WebP в `public/map/` и запишет их положение в `src/data/map-layers.generated.ts`. Из `art-src/map-preview.png` он же сделает превью ссылки (`public/og.jpg`) и обложку карты на главной (`public/map-cover.webp`).
4. Закоммитьте изменения. Vercel пересоберёт сайт сам.

**Новая локация:** положите `новый-id.png` в `art-src/map/`, выполните `npm run map` и добавьте в `world.ts` место с `layer: "новый-id"` и `at` (где стоит подпись).

**Море** вокруг материка рисует шейдер `src/components/Sea.tsx`: полосы глубины, прибой, кольца пены, значки волн. Берег он берёт из `public/map/sea.png` — эту карту расстояний `npm run map` строит по силуэту слоя `materik`, так что после перерисовки материка волны сами подстроятся под новый берег. Цвета, ширина полос и скорость волн — в блоке «настройки» в начале шейдера. Без WebGL вместо шейдера будет ровный цвет `--sea` из `app/globals.css`.

**Порядок слоёв** (что рисуется поверх чего) задан списком `ORDER` в `scripts/build-map.mjs`. Слои, которых нет в списке, встают по нижнему краю: что ниже на карте, то ближе к зрителю.

**Чёткость:** сейчас при сильном приближении (например, к домам Кружья) рисунок немного мылится. Если в Procreate холст можно сделать вдвое больше (7680×4320), экспортируйте слои в этом размере. Больше ничего менять не нужно, координаты в процентах останутся прежними.

## Отдельные картинки сцен и комнат

- **Сцена:** если локации нужен свой детальный рисунок, положите его в `public/scenes/` и сделайте место типом `scene` с `image: "/scenes/имя.webp"` и `aspect` (ширина, делённая на высоту). Точки внутри задаются через `at` в процентах этой картинки.
- **Комната:** положите `public/rooms/miron.webp` и добавьте жителю в `npcs.ts` строку `roomImage: "/rooms/miron.webp"`. Персонаж-заглушка пока остаётся поверх комнаты.

## Разговоры с жителями: бесплатно

Сервер пробует сервисы по очереди: **Gemini → Groq → Cloudflare Workers AI**. Если все недоступны, житель отвечает заготовленными фразами из `npcs.ts`. Подойдёт любой набор ключей, даже пустой.

| Переменная | Где взять |
|---|---|
| `GEMINI_API_KEY` | https://aistudio.google.com/apikey |
| `GROQ_API_KEY` | https://console.groq.com/keys |
| `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN` | панель Cloudflare → Workers AI (токен с правом Workers AI) |

Для запуска на своём компьютере скопируйте `.env.example` в `.env.local` и вставьте ключи.

**Не привязывайте карту ни к одному из сервисов.** Тогда платить нечем: когда дневной лимит заканчивается, сервис отказывает, и отвечает следующий. Бесплатные лимиты и названия моделей иногда меняются. Модель можно поменять переменными `GEMINI_MODEL`, `GROQ_MODEL` и `CLOUDFLARE_MODEL`.

Одному посетителю можно отправить 30 сообщений за 10 минут. Число меняется переменной `CHAT_LIMIT_PER_10_MIN`.
